# RAQEEB images

New screenshots, team photos and links go in the top-level `uploads/` folder (see `uploads/README.md`).

This folder still works for the older file names, which are used when `uploads/` has no image for a slot:

- app/screen-01.png ... app/screen-06.png: patient app screenshots (portrait)
- dashboard/dashboard-01.png ... dashboard/dashboard-05.png: doctor dashboard screenshots (landscape)

Images uploaded through the Website Editor are stored only in the browser that uploaded them.
